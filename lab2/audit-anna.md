\# Аудит специфікації — Анна



\## 1. Мета аудиту



Перевірити відповідність REQ-05–REQ-08, User Stories US-04–US-07 і сценаріїв SC-04–SC-07. Окремо перевірити варіанти використання оплати, повторної оплати, перегляду результату та керування товарами й категоріями.



\## 2. Результати аудиту



| Об'єкт перевірки | Виявлена проблема | Рішення |

|---|---|---|

| US-07 | Історію було сформульовано від імені платіжного сервісу | Замінено на історію покупця про перегляд результату оплати |

| REQ-05 / SC-04 | Потрібно перевірити збереження статусу та суми успішного платежу | Уточнено очікуваний результат |

| REQ-06 / SC-05 | Недостатньо явно перевірялося збереження першої невдалої спроби | Додано запис failed, окремий запис повторної спроби й збереження попереднього запису |

| REQ-07 / SC-06 | Не перевірялося редагування наявного товару | Додано оновлення без створення дубліката |

| REQ-08 / SC-07 | Потрібно перевірити доступність створеної категорії для товарів | Додано перевірку доступності категорії |

| Діаграма варіантів використання | Відсутній окремий варіант перегляду результату оплати | Потрібно додати UC-09 та перегенерувати PNG |



\## 3. Перевірка платіжної логіки



У специфікації визначено, що одне замовлення може мати кілька записів Payment. Невдала спроба не видаляється та не перезаписується під час повторної оплати. Кожна повторна спроба має власний запис.



Зовнішній ідентифікатор транзакції не додається до моделі як обов'язковий атрибут, оскільки такого критерію немає в поточних вимогах.



\## 4. Перевірка керування каталогом



SC-06 перевіряє створення товару, оновлення наявного товару, збереження зв'язку з категорією та відхилення від'ємної ціни. SC-07 перевіряє створення категорії та її доступність для товарів.



\## 5. Підсумок



Для REQ-05–REQ-08 визначено зв'язки з User Stories і сценаріями приймання. У специфікації уточнено поведінку повторної оплати, керування товарами та категоріями. Окремим залишковим завданням є оновлення діаграми й перевірка її відповідності актуальній специфікації
