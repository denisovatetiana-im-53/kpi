# ADR-001: Вибір нотації для моделювання процесу оплати

## Статус

Прийнято.

## Контекст

Під час виконання лабораторної роботи №4 нам потрібно було описати процес оплати замовлення UC-04 «Оплатити замовлення» у вигляді однієї точної моделі.

Процес містить послідовність дій покупця та онлайн-магазину, взаємодію з платіжним сервісом, розгалуження залежно від результату оплати, обробку тайм-ауту та можливість повторної спроби.

## Розглянуті варіанти

1. **PlantUML Activity** — дає змогу показати послідовність дій, ролі учасників, умови переходів і паралельні гілки.
2. **BPMN 2.0** — підходить для детального опису бізнес-процесів, але для нашого сценарію є складнішим у побудові.
3. **Mermaid State Diagram** — добре показує стани об'єкта, але менш зручна для відображення послідовності дій кількох учасників.

## Рішення

Ми обрали PlantUML Activity, оскільки ця нотація дає змогу наочно показати дії покупця, онлайн-магазину та платіжного сервісу, розгалуження для успішної, відхиленої та непідтвердженої оплати, а також паралельні гілки процесу.

## Наслідки

Обрана нотація дозволяє перевірити логіку процесу, наявність умов переходів, обробку тайм-ауту та повторної оплати.

Діаграма узгоджується зі специфікацією `lab4/spec.md`, варіантом використання UC-04 та Sequence-діаграмами лабораторної роботи №3.
