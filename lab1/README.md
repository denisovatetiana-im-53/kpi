# Лабораторна робота №1 — ER-модель

## Домен

**Онлайн-магазин**

## Опис

У цій роботі розглядається предметна область онлайн-магазину.
Система зберігає інформацію про користувачів, товари, категорії,
замовлення та платежі.

Користувач може створювати замовлення, які містять один або декілька
товарів. Для кожного товару в замовленні зберігається його кількість
та ціна на момент оформлення замовлення.

## Мета

Побудувати ER-модель предметної області, визначити сутності,
їх атрибути, первинні та зовнішні ключі, зв'язки і кардинальності.

## Структура

- `spec.md` — специфікація та критерії прийняття.
- `er-model.md` — декларативний опис ER-моделі.
- `DEFENSE.md` — пояснення прийнятих рішень та проведеного аудиту.
- `adr/` — архітектурні рішення.
- `ai/` — слід використання AI.
- `renders/` — рендер ER-діаграми.
